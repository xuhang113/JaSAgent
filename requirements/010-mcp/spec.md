# 010 MCP

## 这次要改什么

现状是工具目录能登记本地工具，但还不能把远端 MCP 工具变成 Tool。这次增加 MCP 客户端登记。不改插件市场，也不让单个远端故障阻止进程启动。

## 模块

这次新增 `jasagent-mcp`。它只依赖 `jasagent-api`。登记出的工具由 app 放进工具目录。

## 改动地方

远端工具的名字是 `mcp_<server>_<tool>`，非字母数字的字符收成下划线。调用前走 `PassGate`。`DENY` 时不调用远端。某个 server 列工具失败时，记录错误并继续登记其他 server，登记方法本身不抛出，进程可以继续启动。

## 数据库

这次不改表。通行证决定沿用已有记录端口。

## 中间件

这次不连接真实的公网 MCP。测试使用进程内的假端点。

## 测试要求

1. 远端工具登记名是 `mcp_<server>_<tool>`。
2. 调用 MCP 工具前会申请通行证。
3. 一个 server 连接失败时，其余工具仍然登记，登记方法不抛出。
4. 通行证为 `DENY` 时不调用远端。
