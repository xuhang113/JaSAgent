## 确认后的口径

1. 本轮编号为 **026-gateway-session-media**。主要改 `jasagent-gateway`、`jasagent-web`；若会话消息或附件账本要对齐，可接线 `jasagent-persist` / `jasagent-app`，但不改运行时模型约定。不改 sidecar、agentpass 和 otel 产品约定。界面仍只用 `jasagent-web`。实现阶段开 PR，不动 `deploy/k8s`。
2. 本轮做会话内图片、语音和视频的上传、取回与 IM 壳展示或播放。模型看图听音放到之后的运行时轮次。本轮不把音视频或图片转给 sidecar/agent。
3. 附件路径（上传、下载、列表、删除及该前缀下所有子路径）由网关自己处理，不能落到「其余 `/api` 粘到 agent」的默认转发。路径规范化后不能绕过前缀。登录以 MySQL 中的会话为准，不用进程内状态，校验与现有用户 `/api` 相同。
4. 附件绑定租户、会话和所有者，不能只凭附件 id 读写。租户 A 不能读、改、删租户 B 的附件。`/admin/cluster` 和 `/admin/jaeger` 不能变成跨租户取附件的旁路；025 里 admin 可见全部租户 traces 的残余不套用到附件。

8. 下载和播放仍要带登录 Cookie，不加公开直链，令牌不要进查询参数。下载响应加 `X-Content-Type-Options: nosniff`，不得用下载响应改写 `JASAGENT_SESSION`。日志和 span 里不写密码、令牌、Authorization、Cookie。
