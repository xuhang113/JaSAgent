# 2026-11-08 默认端口改为 18721

- 日期：2026-11-08（Asia/Shanghai）
- 做了什么：产品默认 HTTP 端口从 8090 改为 18721。未设置 `JASAGENT_PORT`、地址文件也不存在时，启动脚本、地址回退和命令行都使用 `http://127.0.0.1:18721`。`JASAGENT_PORT` 和 `JASAGENT_HOST` 仍可覆盖。
- 涉及模块：jasagent-app、scripts、jasagent-web
- 怎么验证：单独的运行时目录里不设置 `JASAGENT_PORT`，执行 `./scripts/start.sh`，标准输出是 `http://127.0.0.1:18721`，进程监听该地址。随后 `./scripts/stop.sh` 退出 0，进程号文件删除，18721 不再监听。
